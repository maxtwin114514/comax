Capabilities

一个能真正动手的智能体

不是聊天框。它在你本机的 Linux 环境里跑命令、读写文件、调用接口，做完把结果交给你。

原生 Rust 引擎
引擎是独立进程，本地 HTTP + WebSocket 与界面通信。长任务在后台跑，界面可随时离开再回来。
内嵌 Linux
PRoot 里的 Debian 环境，apt、python3、node、git 开箱可用，离线解包、不联网也能装好。
真实工具
读写与批量编辑文件、跑 shell、联网搜索与抓取、下载、生成图片、执行脚本 —— 全是真操作，不是建议。
控制模式
通过无障碍直接操作手机屏幕：读界面、点按钮、填输入框、截屏看图。切到别的 App 也有悬浮球显示进度。
多智能体协同
子代理并行执行、AI 工作室多人协作、群聊室分工。长任务可以拆开同时推进。
技能与 MCP
技能是一个目录加一份说明，按需加载；MCP 接外部工具。两者都能在应用内安装、切换、卸载。
任意模型
OpenAI 兼容、OpenAI Responses、Anthropic、Gemini 四类协议，自带常用服务商预设，也能填任意兼容端点。
数据在本地
会话、文件、密钥都在你自己的设备上。模型请求只发给你配置的服务商，没有第三方统计。

1.5.5o2 更新说明

2026-11 发布 · 制作人：晚风

修复视觉模型“看不见图”：现在随消息发送的图片会真正进入请求（OpenAI / Responses / Anthropic / Gemini 四套协议分别转成 image_url、input_image、image、inlineData），不再被静默丢弃。

OCR 不可用时给出可执行替代：未装 tesseract 时明确建议改用看图，并给出安装命令，而不是只回一句“不可用”。

官网重做：改为极简排版，去掉装饰性动画与玻璃卡片，信息层级靠字号与留白。

FAQ

常见问题

需要 Root、电脑或数据线吗？

都不需要。引擎与 Linux 环境都跑在应用私有目录里，安装后首次启动会自行解包。控制手机界面用的是系统无障碍权限。

它在做事的时候我还能正常用手机吗？

可以。引擎是独立进程，任务在后台继续跑；控制模式操作屏幕时可以切走，悬浮球会显示当前进度，回来能接着看。

收费吗？

Comax 基于 Apache-2.0，本身免费。模型调用由你配置的服务商按其价格计费，花费取决于你的套餐与任务长短。

支持哪些手机？

Android 7.0 及以上、arm64-v8a 机型。截屏与部分控制能力需要 Android 11+。

模型怎么选？

支持图像输入和工具调用的模型都可以接入。常用服务商有预设，也能填任意兼容端点，包括本地运行的模型。

我的对话会上传到哪里？

只保存在你手机本地。只有发消息时，文本与图片会发送给你配置的模型服务商；应用不做第三方统计或遥测。
