# Comax 1.5.2-flash Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 发布 Comax 1.5.2-flash，完成隐私清理、控制模式重构、系统默认手机助手、推理能力适配、MCP 编辑器及会话/计划 UI 修复。

**Architecture:** 原生 Android 负责系统助理角色、录音、胶囊和无障碍手势；Rust 本地引擎负责转写代理、模型能力、MCP 配置和权威计划事件；Vue 前端只管理会话状态与配置界面。跨层数据都走现有带引擎令牌的 loopback API 或明确的 JS bridge，不新增远程后台服务。

**Tech Stack:** Java/Android VoiceInteraction API、Rust/Axum/Serde/Tokio、Vue 3/Pinia/TypeScript、GSAP、Gradle 9.2.1。

**Spec:** `docs/superpowers/specs/2026-10-09-comax-1.5.2-flash-design.md`

## Global Constraints

- 版本固定为 `1.5.2-flash` / versionCode `78`。
- 手机助手只使用 Android 官方默认助理机制，不拦截电源键；ROM 是否把长按电源键映射给默认助理由系统决定。
- 控制模式默认只显示悬浮球；思考过程使用独立单行覆盖层，不在输入卡中追加行。
- 不发送版本日活；保留 `latest.json` 更新检查。
- 所有新增 Web 动画遵守 `coomi.allAnimationsOff` 和 `prefers-reduced-motion`。
- 未知模型不伪造推理能力；探测失败不能阻止普通模型使用。
- MCP 密钥值回读时打码，保存掩码值不得覆盖原密钥。
- 未经用户要求不导出 APK；完成后同步官网与 GitHub，推送前扫描凭据。
