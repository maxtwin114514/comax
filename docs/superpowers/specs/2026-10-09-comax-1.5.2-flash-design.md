# Comax 1.5.2-flash 设计

## 目标与边界

本版同时修复控制模式、会话渲染、推理强度、MCP 与计划进度，并新增 Android 系统默认助理能力。版本为 `1.5.2-flash`，versionCode 78。

手机助手采用 Android 官方默认助理机制。Comax 注册为可选数字助理，由用户在系统授权页手动设为默认；长按电源键是否启动默认助理由 ROM 的按键设置决定。应用不拦截电源键，不伪装系统权限，也不承诺绕过超级小爱、小布等厂商限制。胶囊从屏幕前摄区域展开只是视觉起点，不调用摄像头。

## 1. 隐私与日活

删除 `CoomiService.reportDailyActive()` 及引擎启动后的调用，APK 不再访问 `updates.septemc.com/.../stats/dau`，也不再发送版本号日活。正常的 `latest.json` 更新检查保留。Skill/MCP 的可关闭社区统计属于另一套现有机制，本次不改变其语义。

## 2. 控制模式悬浮层

控制模式启动后默认只显示悬浮球，不自动弹出输入卡片。悬浮球改为蓝白轻量胶囊球样式，保留拖动能力；点击后以 `scale + alpha + translation` 展开任务输入卡，关闭时反向播放，避免动画宽高造成布局抖动。

思考过程从输入卡中移出，改为屏幕顶部独立、不可触摸、单行省略的状态条。它只更新同一个 TextView，不新增行；reasoning chunk 在前端缓冲后以“最新完整片段”覆盖。工具状态也复用该行。展开卡只保留任务输入、发送和必要快捷动作。

点击/长按前显示坐标反馈环，滑动显示短暂方向轨迹；反馈层使用 `FLAG_NOT_TOUCHABLE | FLAG_NOT_FOCUSABLE`，不会拦截目标应用。执行手势时若悬浮卡已收起，不再重复切换 WindowManager 状态。

性能改造：
- 文件命令队列使用 `FileObserver` 唤醒，短周期扫描只作为兜底；
- 悬浮层收起操作幂等，去掉每条命令前 800ms 的重复等待；
- Gesture callback 只等待实际手势完成，按手势时长设置上限；
- read_screen 在窗口内容未变化时短暂复用快照，窗口事件发生后立即失效；
- swipe 期间不重建、展开或闪烁悬浮卡。

## 3. 系统默认手机助手

新增以下原生组件：
- `CoomiAssistantSetupActivity`：控制台入口、权限与模型配置；
- `CoomiVoiceInteractionService`：Android 默认助理服务；
- `CoomiVoiceInteractionSessionService` 与 `CoomiVoiceInteractionSession`：系统唤醒后的胶囊 UI；
- `AssistantSettingsStore`：本机持久化启用状态、STT Provider、STT 模型、语言和助理会话 ID。

控制台新增“手机助手”入口。设置页逐项展示：默认助理角色、麦克风、无障碍、悬浮窗、自启动、引擎状态。只有默认助理角色、麦克风与可用语音模型满足后才显示“已就绪”；权限仍由 Android/ROM 页面授权。

唤醒后，全屏透明 VoiceInteractionSession 在屏幕顶部中心显示胶囊，动画从前摄位置的小点展开。胶囊状态依次为“正在聆听、正在识别、正在执行、完成/失败”。录音有清晰状态，最长 15 秒，检测静音后自动结束，不在未唤醒时后台录音。

语音识别默认使用已配置 Provider 的 OpenAI 兼容音频转写接口 `/audio/transcriptions`，设置中选择 Provider 与模型，并允许手填模型名。音频和凭据由本机引擎处理，原生 UI 不回显 API Key；识别服务不可用时可选择 Android 系统语音识别作为回退。转写文本提交到现有 `/api/control/tasks`，执行模型沿用当前活动 Provider/模型，因此手机助手继续通过 `ui_automation` 控制手机。

## 4. 对话恢复与动效

思考块正文使用可中断的折叠过渡，图标旋转、正文高度与透明度同步；全局“关闭所有动画”或系统 reduced motion 时立即切换。

WebView 不可见时，前端 ACK 事件但暂存 UI 事件；恢复可见后等待短暂静默窗口，再在同一个 Vue 更新周期批量应用，避免工具和文字逐字回放。正常前台流式输出不受影响。

点击消息“编辑”后，原消息显示一次柔和高亮，编辑提示条平滑进入；取消或发送时反向退出。重发截断仍以引擎 `edit_turn` 为权威，不延迟网络命令。

## 5. 会话 Token

`/api/sessions` 已提供持久化 usage。前端同步会话列表时把 `usage.total_tokens` 写入 SessionMeta，实时 `usage_update` 同步当前会话。侧栏在时间和轮数后显示格式化总 Token；引擎值优先，localStorage 仅缓存。

## 6. 推理强度

协议增加 `off`，界面改为带刻度的拖拽条：关闭、自动、低、中、高、超高。模型能力表返回该模型支持的档位和来源，滑块只允许落在可用档位；选择自动时按提示长度映射到最接近的支持档位。

能力来源按优先级合并：Provider `/models` 元数据、已保存的模型参数、能力缓存、模型名保守推断。首次实际请求若 Provider 拒绝某个推理字段或档位，现有 400 fallback 降级并回写能力缓存，后续不再重复发送不兼容参数。能力探测不因失败阻止普通模型使用。

`off` 表示优先发送该协议明确支持的关闭值；未知协议则移除推理字段并将 `thinking_enabled=false`。强制推理模型无法真正关闭时，UI 显示“模型固定推理”，而不是伪称已关闭。

## 7. 自定义 MCP

自定义 MCP 仍是全局能力，入口放在“拓展管理 > MCP”。原始 JSON 文本框升级为结构化编辑页：
- 公共字段：名称、传输方式、启用状态；
- stdio：command、args、cwd、env、framing；
- HTTP/SSE：URL、headers；
- 高级 JSON 可查看和编辑最终配置。

新增本地、带引擎令牌保护的 CRUD 与测试接口。支持新建、编辑、复制、连接测试、启停和删除；保存后热重载 MCP，不重启引擎。测试失败不会破坏其它 MCP，也允许用户保存为停用配置。env/headers 在列表与编辑回读中打码，未修改的掩码值由后端保留。

## 8. 计划进度

不再把持久 Loop 的轮数当作计划步骤。`AgentEvent::PlanUpdated` 向 Web 发送完整 `plan_updated`：步骤文字、pending/in_progress/completed 状态和说明。前端按 completed/total 计算进度，当前步骤只来自 in_progress；全部完成后显示 100%，短暂保留后收起。展开区展示全部步骤及真实状态。

## API 与兼容

新增接口使用现有 `/api` 与引擎令牌：
- `POST /api/assistant/transcribe`
- `GET/POST/PUT/DELETE /api/mcp/servers...`
- `POST /api/mcp/servers/test`
- `GET /api/model-capabilities?provider_id=&model=`

旧的 `/api/catalog/mcp/custom` 与旧会话元数据继续兼容。旧 reasoning effort 值仍可读取；缺失时默认 `auto`。

## 验证

- Rust：Provider 推理档位/off/fallback、MCP CRUD/掩码/测试、plan_updated、assistant transcription 路由单测；
- Web：vue-tsc + Vite、会话批量恢复、Token 同步、滑块档位、MCP 表单、折叠动效静态回归；
- Android：Javac/Gradle、Manifest voice service 合法性、默认助理角色请求、麦克风拒绝与服务不可用降级；
- 真机必须验证：HyperOS 默认助理选择、长按电源键 ROM 映射、胶囊位置、录音、控制点击/滑动与输入法；本地构建环境不能替代这些结论。
